## CRITICAL PATH

These 5 tasks are blocking all others. If they slip, everything slips.

1. **Airtable + n8n setup (Day 1)** — You can't track prospects or run agents without this
2. **Research Agent + Outreach Agent built (Days 4–5)** — Without these, you're manually researching and writing every message (2 hours per prospect)
3. **Landing page live (Day 6)** — Something to send prospects to
4. **First 10 outreach messages sent (Day 8)** — Momentum and learning from real replies
5. **First proposal sent (Day 16)** — Proves the system works end-to-end

If any of these slip by 2+ days, the rest of the month slips.

## RISKS & MITIGATION

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|-----------|
| **n8n setup takes longer than 2 hours** | Medium | High | Pre-watch 2 n8n tutorials. Have backup: if n8n fails, use Make.com (slower but more reliable). Alternatively, manual workflow Week 1 (no agents, you do research + writing by hand) |
| **First prospects don't reply (reply rate < 10%)** | Low-Medium | High | Days 8–9: send to 20+ (not 10), use multiple channels. Analyze replies from first 3 to see what works. Pivot messaging if needed. |
| **Airtable API rate limit hit** | Low | Medium | Airtable free tier: 100k API calls/month. One agent call per prospect ≈ 10 API calls. You'd need 10k prospects to hit limit. Unlikely Month 1. If it happens, batch updates (run agents 2x/day instead of real-time). |
| **Customer doesn't send data on time** | Medium | High | Set expectation in proposal: "We need data by [date] to deliver by [date]." Follow up Day 1, Day 2 if not received. Offer 15-min call to help export if stuck. |
| **First audit doesn't show clear ROI** | Low | Very High | This destroys the whole offer. Mitigation: Pick first client carefully. Preferably someone with clean data and a clear problem (high churn or unclear segment value). If audit inconclusive, take responsibility, iterate, offer discount for second audit. |
| **You burn out / don't focus** | Medium | Very High | Week 1 is setup (2-3 hours/day focused work). Week 2–4 is 4–5 hours/day (outreach + calls + delivery). Block calendar. Set office hours. Don't work weekends (except email check-in Sundays). |

## DECISION TREE: First Client Should Be...

**Option A: Discounted First Audit ($250–350)**
- Pick someone you know personally or through network
- Lower stakes
- Testimonial guaranteed
- Quick revenue boost
- Best choice if: You want to validate the process and reduce risk

**Option B: Free Audit (100% off)**
- Pick someone with excellent, clean data
- Mutual NDA (your learnings are also valuable)
- Testimonial and referral are the payment
- Best choice if: You want to minimize risk and maximize learning

**Option C: Full Price First Audit ($500–1,500)**
- Pick someone who's clearly in pain and convinced of value
- Sets precedent for pricing
- Full commitment = higher follow-through
- Best choice if: You're confident in the offer and willing to deliver excellence

**Recommendation:** Start with Option A (discounted). Deliver perfectly. Ask for testimonial. Use Week 2 learnings for full-price clients in Week 3–4.
